## Чтение файлов CSV и Excel (`src/file_readers.py`)

Модуль предоставляет функционал для загрузки транзакций из CSV и Excel (.xlsx) файлов:

- `read_csv_file(file_path)` — считывает транзакции из CSV-файла и возвращает их в виде списка словарей.
- `read_excel_file(file_path)` — считывает транзакции из XLSX-файла и возвращает их в виде списка словарей.

В случае если файл отсутствует, пуст или поврежден, функции возвращают пустой список `[]`.
