Проект банковского виджета: маскирование карт/счетов, обработка операций, генераторы, логирование, чтение JSON и конвертация валют.

## Чтение файлов CSV и Excel (`src/file_readers.py`)

Модуль предоставляет функционал для загрузки транзакций из CSV и Excel (.xlsx) файлов:

- `read_csv_file(file_path)` — считывает транзакции из CSV-файла и возвращает их в виде списка словарей.
- `read_excel_file(file_path)` — считывает транзакции из XLSX-файла и возвращает их в виде списка словарей.

В случае если файл отсутствует, пуст или поврежден, функции возвращают пустой список `[]`.

## Интерактивный CLI-интерфейс (`main.py`)

Программа предоставляет пользовательское меню в консоли для загрузки, фильтрации и отображения транзакций:
1. Выбор источника данных (JSON, CSV или XLSX).
2. Фильтрация по статусу (EXECUTED, CANCELED, PENDING).
3. Сортировка по дате (по возрастанию / по убыванию).
4. Фильтрация рублевых транзакций.
5. Поиск по слову в описании с использованием регулярных выражений (`src/search.py`).

## Модуль поиска и подсчета категорий (`src/search.py`)

- `process_bank_search(data, search)` — фильтрует транзакции по совпадению строки поиска в поле `description` с помощью регулярных выражений.
- `process_bank_operations(data, categories)` — подсчитывает количество операций для каждой категории из списка с помощью `collections.Counter`.
